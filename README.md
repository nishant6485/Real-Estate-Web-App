🏠 Real Estate Web App:
🔗 Live Demo: https://real-estate-web-app-alpha.vercel.app/

💡 Overview:
A modern, responsive, and visually engaging Real Estate Web Application built with React and CSS.
This project showcases an elegant design with smooth animations, a dark/light mode switch, and an intuitive interface for exploring property listings.

🌟 Features:
✅ Responsive Design – Fully optimized for all screen sizes
🌙 Dark/Light Mode Toggle – User-friendly theme switching
🎞️ AOS Scroll Animations – Smooth entrance animations for each section
⬆️ Scroll to Top Button – Instantly jump to the top of the page
🧭 Smooth Navigation – Seamless section transitions using React Scroll
💡 Clean UI/UX – Professional and elegant layout

⚙️ Tech Stack:
Category  || Technologies
Frontend   :  React (Vite)
Styling	   :  CSS
Animations :  AOS (Animate On Scroll)
Deployment :  Vercel
